# Aurelle — Premium Beauty & Lifestyle E-commerce (Frontend)

Built with Next.js (App Router) + JavaScript + Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Notes
- This is a frontend-only build. Login/Register, Checkout, Forgot/Reset Password forms
  currently simulate actions (no real backend/database yet).
- Cart & Wishlist persist via localStorage.
